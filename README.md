### What I'm working on

#### Building

- **IT Inventory System** *(in progress)* - Discovers and classifies the devices on an authorized network (PCs, servers, printers, cameras, IP phones, VMs and more), applies OS and software updates one program at a time with explicit confirmation, and keeps a per-person audit trail. PHP web panel with roles and MariaDB, plus a Python network engine.
- **VidRadar** *(in progress)* - Finds YouTube videos that perform far above their channel's average, to spot what topics and formats are working. It grows from my public [YouTube Outliers](https://github.com/Juanan242?tab=repositories&q=outliers) project.
- **Sparking Zero app** *(in progress)* - Web app for Dragon Ball Sparking Zero players: ranked matchmaking, tournaments and team building.
